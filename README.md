# Projects

Each folder is a self-contained project with its own README, setup and tests.

| Project | What it is |
|---|---|
| [1-image-colorization](1-image-colorization/) | Image colorization website: Python backend with a simple web frontend. |
| [2-order-processing-microservices](2-order-processing-microservices/) | Event-driven order flow: six Spring Boot microservices talking through Kafka (saga, outbox, JWT, observability). |
| [3-movie-reservation-system](3-movie-reservation-system/) | Cinema booking REST API: showtimes, timed seat holds, Stripe Checkout payments and refunds. |
| [4-hr-management-system](4-hr-management-system/) | HR platform: Spring Boot 3.5 / Java 21, PostgreSQL and a React + TypeScript frontend. |
| [5-ai-document-assistant](5-ai-document-assistant/) | Chat with a PDF: retrieval-augmented answers with page citations (Spring Boot, pgvector, Gemini, React). |
